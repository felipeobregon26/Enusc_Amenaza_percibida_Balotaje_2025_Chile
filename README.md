# Enusc_Amenaza_percibida_Balotaje_2025_Chile
El presente estudio tiene como finalidad construir un modelo que explore y visualice indicadores de victimización y amenaza delictual percibida, durante la última década en Chile. Además, se evaluará la posibilidad de identificar relaciones entre los datos de la ENUSC y los resultados de las últimas elecciones presidenciales, a nivel comunal y/o regional.
